How to use cookies.txt (for stories)
  1. Install the browser extension "Get cookies.txt LOCALLY"
  2. Log in to Instagram in your browser
  3. Click the extension and export cookies for instagram.com
  4. Save the file as cookies.txt in the project root folder
  5. Check the "Use cookies.txt" box above
